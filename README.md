# Sonic.EXE - بازی هورور پلتفرمر

یک بازی ترسناک الهام‌گرفته از creepypasta معروف Sonic the Hedgehog

---

## نسخه JavaScript (مرورگر)

**بدون نصب** – فقط فایل HTML رو در مرورگر باز کن:

```
sonic_exe.html
```

یا دوبار کلیک روی فایل یا راست‌کلیک → Open with → مرورگر

---

## نسخه Python (Pygame)

### نصب

```bash
pip install -r requirements.txt
```

### اجرا

```bash
python sonic_exe_game.py
```

## کنترل‌ها

- **فلش‌ها یا WASD**: حرکت
- **Space**: پریدن
- **ESC**: خروج

## هدف بازی

- **۲۰ حلقه** جمع کن تا برنده شوی
